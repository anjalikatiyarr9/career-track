# CareerTrack – Job Application Tracker

CareerTrack is a responsive job application tracking dashboard built with Next.js and Tailwind CSS. It helps users organize job applications, track interview progress, and monitor their job search through a centralized dashboard.

## Features

- **Dashboard:** View total applications, interviews, offers, and rejections.
- **Application Management:** Add, edit, delete, and search job applications.
- **Pipeline Tracking:** Update application statuses and organize applications by stage.
- **Analytics:** View application statistics and status distribution.
- **Persistent Storage:** Application data is saved using browser localStorage.
- **Responsive Design:** Works across desktop and mobile devices.

## Tech Stack

- Next.js
- React.js
- JavaScript
- Tailwind CSS
- HTML5
- Browser localStorage
- Git and GitHub

## Getting Started

Clone the repository:

```bash
git clone https://github.com/anjalikatiyarr9/career-track.git
```

Navigate into the project:

```bash
cd career-track
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

## Data Storage

CareerTrack currently uses browser localStorage to save application data. Data remains available in the same browser on the same device after refreshing or reopening the application.
